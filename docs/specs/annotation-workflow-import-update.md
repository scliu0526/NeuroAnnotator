# 圖片匯入與標註操作增量規格

## Problem Statement

使用者在匯入大量圖片時看不到可量化的進度；SEG 畫筆閉環包住既有同類別標註時，原有填色可能反而消失。類別顏色、圖片清單資訊、選取回饋與標註集切換也不足以支援連續標註。圖片刪除、輸入控制及啟動視窗需要一致而可預測的操作方式。

## Solution

以已處理圖片數顯示匯入進度，僅將新匯入的 BMP 轉成 PNG；修正 SEG 閉環與既有同類別區域的聯集。統一類別顏色交換格式，補足標註頁清單、選取外框與預覽，並提供單一建立標註集入口、跨頁同步切換、兩種刪圖操作、雙向同步的筆寬／透明度控制，以及啟動最大化。

## User Stories

1. 身為使用者，我希望匯入時看到已處理與總張數，以便知道作業進度。
2. 身為使用者，我希望看到成功與失敗張數，以便判斷匯入結果。
3. 身為使用者，我希望取消後保留已成功匯入的圖片，以便不必重做已完成的工作。
4. 身為使用者，我希望新匯入的 BMP 轉為 PNG，以便專案與交換檔名反映實際格式。
5. 身為使用者，我希望 PNG、JPG、JPEG 保持原格式，以便避免不必要的轉檔。
6. 身為使用者，我希望轉檔後撞名的圖片仍能全部匯入，以便保留不同來源的圖片。
7. 身為使用者，我希望缺失的轉檔圖片能用原始 BMP 重新連結，以便恢復其標註。
8. 身為使用者，我希望 SEG 畫筆閉環後整個圈內成為標註，以便建立完整區域。
9. 身為使用者，我希望閉環與既有同類別標註合併且不抹除舊填色，以便保留已完成的標註。
10. 身為使用者，我希望不同類別的重疊標註保持獨立，以便表達同一像素的多種標籤。
11. 身為使用者，我希望新標註集的 `class1` 與新增類別取得隨機 RGB 顏色，以便不總是固定紅色。
12. 身為使用者，我希望同一標註集的新類別不取得已使用的相同 RGB 值，以便類別不完全同色。
13. 身為使用者，我希望標註頁清單顯示每張圖片在目前標註集中的類別，以便快速找到圖片。
14. 身為使用者，我希望 OBD／SEG 的清單顯示現存標註物件總數，以便判斷標註密度。
15. 身為使用者，我希望按類別或數量標頭排序，以便按目前標註狀態瀏覽圖片。
16. 身為使用者，我希望未標註圖片在類別升冪與降冪排序時都排最後，以便先查看有標註的圖片。
17. 身為使用者，我希望從單一入口選擇 CLA、OBD 或 SEG 並輸入名稱，以便一次完成新增標註集。
18. 身為使用者，我希望多選或全選的每個 OBD／SEG 區塊都顯示外框與八個控制點，以便辨認選取範圍。
19. 身為使用者，我希望拖曳控制點只變形它所屬的區塊，以便避免意外縮放整組。
20. 身為使用者，我希望標註與擦除工具的畫布預覽使用目前類別顏色及固定 40% 透明度，以便預覽不受結果透明度設定干擾。
21. 身為使用者，我希望在資料集分配頁直接切換標註集，且其他頁面同步，以便不必先返回標註頁。
22. 身為使用者，我希望刪除 Ctrl／Shift 明確選取的圖片，以便只移除指定圖片。
23. 身為使用者，我希望一鍵選擇刪除整個專案的圖片，並在確認前看見影響張數，以便避免誤解刪除範圍。
24. 身為使用者，我希望新儲存及匯出的類別顏色採 `rgba(R, G, B, 1)`，以便格式一致。
25. 身為使用者，我希望自訂色彩帶有 `-custom` 後綴，而隨機色不帶，以便保留選色來源。
26. 身為使用者，我希望無效顏色使標註 JSON 整批拒絕，以便不產生部分匯入或悄悄改色。
27. 身為使用者，我希望筆寬同時可輸入數值或拖動滑條，以便精確及快速調整。
28. 身為使用者，我希望透明度同時可拖動滑條或輸入數值，以便精確及快速調整。
29. 身為使用者，我希望啟動時主視窗最大化，以便立即使用完整工作空間。
30. 身為專案維護者，我希望本次修改先在獨立分支完成，待我確認全部結果後才合併 `main`，以便親自驗收變更。

## Implementation Decisions

- 本增量只改變今後新匯入的圖片。PNG、JPG、JPEG 保留來源格式與內容；BMP 轉成 PNG；不擴充支援格式，不遷移現有專案圖片。原有圖片的顯示檔名與標註關聯保持不變。
- 匯入批次先列舉待處理圖片。每張圖片完成寫入或確定失敗後，已處理數增加一；進度顯示已處理／總數及成功、失敗數。取消在單張圖片的安全邊界生效，保留先前成功項目；失敗或取消不得留下半成品。
- 新匯入 BMP 的顯示及 JSON `fileName` 使用 `.png`；同名時產生唯一後綴。新匯入 JPG／JPEG／PNG 保留其副檔名。圖片 ZIP 使用專案受管理檔案的實際格式，且不再轉檔。
- 轉檔圖片仍保留辨識原始來源所需的資訊，以便以相同來源內容重新連結。標註 JSON 僅依轉換後的顯示檔名映射 BMP 圖片；舊 `.bmp` 名稱不設自動別名，無法唯一映射時整批拒絕。
- SEG 畫筆沿用既有閉合操作及 Non-Zero Winding 幾何契約。閉環內新填色與既有同類別區域取聯集；原有同類別填色面積不得因新增而減少。不同類別可重疊；只接觸邊或角、既有物件變形重疊的既有規則不變。先重現並定位缺陷，再決定修正位置。
- `class1` 與手動新增類別的顏色從完整 RGB 範圍隨機產生；與同一標註集現有 RGB 值完全相同時重抽。不要求視覺色差，使用者可以自行改色。
- 類別顏色新儲存與新匯出採 `rgba(R, G, B, 1)`，逗號後有空格。可讀取既有十六進位及有效 `rgba` 值；匯入值的 alpha 統一為 `1`。使用者以自訂色彩選擇器改色時加 `-custom`；隨機色不加；有效匯入值已有後綴時保留。無效或超出範圍的 JSON 顏色使整份匯入原子失敗。畫布、類別清單與選色器均須能顯示正規化後的顏色。
- 標註頁圖片清單依目前標註集顯示去重類別名稱。OBD／SEG 的數量是現存物件總數；CLA 只顯示類別，不顯示數量。類別排序先排序單張圖的名稱，再比較完整清單；升冪與降冪時空白均排最後。數量按整數升冪／降冪排序；相同鍵值保持穩定順序。
- 一個新增標註集入口在同一視窗取得型別與名稱；建立成功後沿用自動切換至新標註集的規則。
- 每個被選取的 OBD／SEG 物件均顯示外接矩形邊框及八個控制點。拖曳控制點只變形所屬物件；群組移動仍套用全部被選物件。重疊控制點的命中應與可見層級一致。
- 所有標註及擦除工具的畫布預覽軌跡使用目前選取類別的 RGB 顏色，alpha 固定為 40%。結果透明度可調，預覽不跟著改變；既有外框、文字與控制點仍保持可辨識。
- 資料集分配頁與標註頁共用目前標註集，從任一頁切換時同步選單與資料；未完成形狀沿用既有切換時捨棄規則。
- 刪除選取圖片只使用明確選取的 ID，支援 Ctrl／Shift 多選；刪除全部使用整個專案的圖片 ID，不受搜尋或篩選影響。兩種操作均顯示張數及不可復原的跨標註集影響，再按確認執行，不要求輸入文字。刪除後維持連續顯示序號，並更新清單與畫布。
- 筆寬數值與滑條同步，範圍 1–100、預設 15；透明度滑條與數值同步，範圍 0–100%、預設 40%。共用筆寬的工作階段記憶與切換標註集時結果透明度重設規則不變。
- 開啟應用程式時主視窗預設最大化；保留使用者在本次工作階段自行調整視窗的能力。
- 本次修改使用新分支 `annotation-workflow-import-update`。文件及後續程式修改先在此分支完成並上傳 GitHub，提供差異與驗收證據；只有使用者確認全部修改完成後，才合併到 `main`。

## Testing Decisions

- 以使用者可觀察的結果、持久化資料及 JSON／ZIP 交換結果為主，不以控制項或私有函式是否存在作為唯一成功條件。優先沿用專案儲存整合、SEG 幾何契約、JSON 往返及薄 WinForms 接線等現有測試縫；只有匯入進度的可觀察事件需要新增最小接線。
- 匯入測試覆蓋混合格式、BMP 像素與實際 PNG 編碼、JPG／JPEG／PNG 內容不變、轉換與原檔撞名、失敗清理、取消後部分成功、重新連結原 BMP、JSON 與 ZIP 名稱，以及現有專案不遷移。
- SEG 測試先重現舊標註變空白；以填色遮罩驗證閉環、部分重疊、完全包住、洞、邊角接觸、自交、不同類別重疊、儲存重開及 Undo／Redo。驗證區域數與填色面積，而非只比較路徑點序。
- 顏色測試覆蓋 `class1` 與手動新增、可控制的亂數來源、同一標註集內精確重複重抽、相近色允許、手動自訂後綴、舊格式讀入、alpha 正規化、JSON 往返及無效值整批零寫入。
- 清單測試覆蓋 CLA／OBD／SEG 欄位差異、多類別完整清單排序、空白在兩種方向均排最後、數量的數字排序、同值穩定順序，以及合併、擦除分裂、刪除、Undo／Redo、匯入、切換標註集後刷新。10,000 張清單使用批次資料取得，不能逐列查庫。
- UI 測試覆蓋單一建立視窗、跨頁標註集同步、多選及全選的逐物件外框和八控制點、控制點只變形所屬物件、各工具 40% 彩色預覽在結果透明度 0／40／100% 時不變、雙向輸入同步、刪除選取與全部的範圍及確認、啟動最大化。
- Release x64 建置與自動測試後，於 Windows 實際檢查 1366×768 與 100%～200% DPI 的控制項可操作性；圖片數量與 SEG 複雜度的既有效能門檻仍適用。

## Out of Scope

- 將現有專案的 BMP／其他圖片批次轉檔，或新增 GIF、TIFF、WebP 等匯入格式。
- 自動接受舊標註 JSON 的 `.bmp` 名稱作為新 `.png` 圖片的別名。
- 依顏色距離排除相近類別顏色，或禁止使用者手動設定重複顏色。
- 對多選物件做整組縮放、旋轉，或依目前篩選結果批次刪圖。
- 改變不同 SEG 類別的重疊規則、既有標註集隔離規則，或將顯示透明度寫入 JSON。
- 在使用者確認全部修改完成前合併 `main`。

## Further Notes

- 本規格是第一版產品規格及標註介面增量規格的後續增量；衝突處以本規格為準，未提及的既有約束持續適用。
- 舊規格「匯入顏色值原樣保留」已由正規化與嚴格驗證決策取代。新 BMP 名稱政策會影響 JSON 對應；既有專案圖片不被改寫。
- SEG 同類別新繪製聯集已是現有領域與 ADR 契約；本次是修正不符合契約的行為。不能只因現有程式有聯集呼叫便宣告缺陷已修復。
