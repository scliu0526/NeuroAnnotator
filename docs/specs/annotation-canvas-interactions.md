# 畫布互動、標註複製與集體旋轉增量規格

## Problem Statement

使用者難以從畫布指標、工具按鈕及類別按鈕辨認下一筆會使用的工具與類別。筆刷折返可能產生尖角或意外封閉填色；畫筆起點與矩形、圓形的預覽不夠清楚。既有選取方式無法直接框選範圍，畫布缺少可見捲軸及右鍵平移，快捷鍵也缺少集中說明。跨圖片重複標註需要重新繪製；多選 SEG 區域無法同步旋轉並預覽各自的外框與控制點。

## Solution

讓畫布指標、繪製預覽、作用中工具與類別提供一致回饋；提供以實際標註區域判定的框選、受邊界限制的捲軸與右鍵平移、顯示標註切換及快捷鍵列表。OBD 物件與 SEG 區域可在同一標註集內以內部快照複製，按原座標貼到一張或多張圖片；多選 SEG 區域可各繞自己的中心同步旋轉。所有資料修改維持既有專案、幾何、Undo/Redo 與 JSON 契約。

## User Stories

1. 身為使用者，我希望畫布指標反映目前標註工具，以便落筆前知道會執行何種操作。
2. 身為使用者，我希望選取模式使用一般箭頭，矩形、圓形與畫筆使用小十字，以便準確看見落點。
3. 身為使用者，我希望筆刷、線型與橡皮擦的指標以目前寬度顯示圓環，以便判斷影響範圍。
4. 身為使用者，我希望筆刷與線型指標顯示 `+`、橡皮擦顯示 `−`，以便分辨新增與去除標註。
5. 身為使用者，我希望筆刷折返時仍像圓筆頭沿路塗抹，以便不出現尖角或意外填滿圈內。
6. 身為使用者，我希望單擊筆刷留下圓點、單擊橡皮擦清除圓形範圍，以便精修小區域。
7. 身為使用者，我希望圓筆頭靠近圖片邊緣時仍完整留在圖片內，以便標註幾何不越界。
8. 身為使用者，我希望畫筆的預覽軌跡更清楚且始終標示起點，以便判斷路徑如何閉合。
9. 身為使用者，我希望矩形與圓形在拖曳時顯示半透明填色與外框，以便預先看見覆蓋範圍。
10. 身為使用者，我希望在選取模式從空白畫布拖曳框選，以便一次選取範圍內的 OBD 物件或 SEG 區域。
11. 身為使用者，我希望框選碰到實際標註區域就能選取，以便選到部分位於框內的物件，而不因 SEG 的洞或外接矩形空白誤選。
12. 身為使用者，我希望一般框選取代原選取、Ctrl+框選加入原選取，以便快速建立想要的多選集合。
13. 身為使用者，我希望從標註本體或控制點開始拖曳時仍能移動、縮放或旋轉，以便框選不妨礙既有編輯。
14. 身為使用者，我希望在標註工具作用中也能按 `F` 適合視窗，以便迅速回到全圖。
15. 身為使用者，我希望未完成操作中按 `F` 取消該次操作並立即適合視窗，以便不留下半成品。
16. 身為使用者，我希望圖片超出畫布時有對應方向的捲軸，且能按住右鍵平移，以便查看放大的圖片。
17. 身為使用者，我希望捲軸、右鍵拖曳及其他平移方式都停在圖片邊緣，以便畫布不露出無謂空白。
18. 身為使用者，我希望作用中的工具按鈕有背景色與外框提示，以便知道下一步的工具模式。
19. 身為使用者，我希望類別按鈕標示目前落筆類別，以便 OBD 或 SEG 新標註使用預期的類別。
20. 身為使用者，我希望同一標註集內切圖時保留落筆類別、切換標註集時回到其第一個類別，以便模式容易預測。
21. 身為使用者，我希望在「說明 → 快捷鍵」查看按鍵及適用情境，以便不用猜測操作方式。
22. 身為使用者，我希望複製已選 OBD 物件或 SEG 區域，並貼回原圖、貼到另一張圖或多張選取圖片，以便重用標註。
23. 身為使用者，我希望貼上的物件保留複製時的類別、幾何、原始像素座標與彼此層級，以便各圖片得到一致結果。
24. 身為使用者，我希望超出目標圖片的複製物件被略過，而同批未超界的物件仍貼上，以便可用標註不被一個超界物件阻擋。
25. 身為使用者，我希望貼上的 SEG 區域保留獨立身分，即使與同類別原區域完全重疊，以便貼回原圖時仍能選取與移動複本。
26. 身為使用者，我希望一次批次貼上能以一次 Undo/Redo 復原或重做，以便不必逐圖操作。
27. 身為使用者，我希望來源標註後續修改或刪除不改變已複製內容，以便貼上的是按 `Ctrl+C` 當下的版本。
28. 身為使用者，我希望複製標註的類別被刪除後，貼上停止並以短暫提示說明原因，以便不會悄悄改成其他類別。
29. 身為使用者，我希望按 `[` 或勾選「顯示標註」切換原圖與疊圖，以便比較影像而不刪除標註。
30. 身為使用者，我希望隱藏標註時不能誤選或編輯既有標註，但仍可新增並看見當次預覽，以便維持原圖檢視下的繪製能力。
31. 身為使用者，我希望在 SEG 標註頁以 `Z`／`X` 每次減少／增加 1 個寬度單位，以便精確調整共用寬度。
32. 身為使用者，我希望繪製中的筆畫保持落筆時寬度，以便中途調整只影響下一筆。
33. 身為使用者，我希望拖曳任一已選 SEG 區域的旋轉控制點時，所有已選區域各繞自身中心旋轉相同角度，以便同步調整方向而不改變彼此中心位置。
34. 身為使用者，我希望旋轉期間每個區域的外框與控制點跟著轉，放開後按最終幾何恢復軸對齊外接矩形，以便看清操作與結果。
35. 身為使用者，我希望任一已選區域將越界時整組停在最後一個合法角度，而多選縮放仍只作用於單一區域，以便操作保持一致。
36. 身為專案維護者，我希望在獨立分支與 Draft PR 檢查修改及測試，並在桌面驗收後才決定是否合併 `main`，以便控制交付品質。

## Implementation Decisions

- 指標以實際落點為中心。選取模式使用一般箭頭；OBD／SEG 矩形、SEG 圓形與畫筆使用小十字；SEG 筆刷、線型與橡皮擦顯示隨縮放反映原圖寬度的圓環，前兩者附 `+`，橡皮擦附 `−`。指標不可遮蔽精確落點。
- SEG 筆刷永遠是有寬度的圓筆頭路徑；接近起點不轉成封閉 PolyGon，也不填滿未被筆頭碰到的內部。畫筆工具仍負責閉合填色區域。筆刷與橡皮擦單擊使用目前寬度的圓形範圍；邊緣落點將中心限制在可容納完整筆頭的位置。不新增圖片小於筆寬的專用 UI 分支，現有幾何邊界不變。
- 畫筆預覽路徑約 3 畫面像素寬，起點在整段標註過程顯示約 8 畫面像素直徑的實心圓；這兩種提示以畫面像素維持可辨識。矩形與圓形預覽顯示半透明填色及清楚外框。預覽沿用目前類別顏色與固定 40% alpha，不跟隨結果透明度設定。
- 選取模式從空白畫布按左鍵拖曳開始框選；從物件或控制點開始仍執行既有編輯。OBD 以矩形、SEG 以實際填色或筆畫區域與框選範圍重疊判定，SEG 外接矩形的空白及洞不算。未按 Ctrl 的框選取代原選取；Ctrl+框選取聯集，已選物件不因再次框到而取消。既有 Ctrl+點選切換語意不變。
- `F` 在圖片與標註頁的非文字輸入狀態都適用，不受標註工具模式限制。操作未完成時按 `F` 先捨棄該次未提交的預覽與拖曳，再立即適合視窗。適合視窗、縮放、滾輪、捲軸及右鍵拖曳共用同一視角與兩軸邊界；圖片在某軸放得下時該軸置中，捲軸隱藏且不可平移。
- 工具按鈕以背景色及外框標示作用中模式，並保留工具名稱提示。類別按鈕保留代表類別的底色，以外框標示目前 OBD／SEG 落筆類別；點類別同時選定未來新增標註的類別，若有已選物件則維持既有改類別操作。CLA 標示目前圖片已指派的類別。OBD／SEG 同集切圖保留落筆類別，每次切換標註集改選目標集第一個類別。
- 主視窗選單提供「說明 → 快捷鍵」列表，列出新舊快捷鍵與適用頁面、工具及文字焦點條件；`Ctrl+Z`／`Ctrl+Shift+Z`／`Ctrl+Y`、文字輸入等原有用途保持。`Z`／`X` 在 SEG 標註頁每次調整共用寬度 1，限制於 1–100；即使目前是其他 SEG 工具也可調整。進行中的有寬度操作鎖定起始寬度，新值由下一筆使用。
- 內部複製內容只在本次程式執行期間存在，不寫入 Windows 剪貼簿；`Ctrl+C` 取得同一標註集內已選 OBD 物件或 SEG 區域的快照。無已選物件時不更新快照。`Ctrl+V` 僅貼到快照所屬的同一標註集；目標為明確選取的圖片，來源圖片若也在目標中同樣貼上。沒有可貼目標或有效物件時不新增完成操作。
- 貼上按原始像素座標逐物件檢查各目標圖片；超界物件靜默略過，合法物件照常貼上。先確認快照引用的類別仍存在；任何類別已刪除時整次貼上停止並顯示短暫 Toast，不改類別。合法複本取得新身分，維持類別、幾何及同批相對層級，排列於目標圖片既有標註上方。SEG 複本不套用「新繪製同類別重疊聯集」；貼上是複製物件，不是新繪製。
- 一次 `Ctrl+V` 的所有成功複本構成單一完成操作及單一 Undo/Redo 記錄；未預期的持久化失敗不得留下部分寫入或歷史紀錄。目前顯示圖片若貼上成功，選取其新複本；不自動切換至其他圖片。
- `[` 與標註頁「顯示標註」勾選同步。隱藏只影響顯示與既有物件命中，不刪除或改寫標註；既有物件不可選取或編輯。新標註的當次預覽可見，提交後按隱藏狀態不顯示結果。狀態在同一專案工作階段跨圖片及標註集維持，重新開啟專案預設顯示，不寫入資料庫或 JSON。
- 多選旋轉只適用 SEG；拖曳任一已選區域的旋轉點，所有已選區域以同一角度各繞自己的中心旋轉。預覽的每個外接矩形與控制點跟隨旋轉；放開後以完成的幾何重新計算 0 度軸對齊外接矩形。只接受所有區域都合法的角度，超界時保持最後一個整組合法預覽。多選的縮放仍只修改控制點所屬區域；OBD 保持軸對齊矩形。
- 不變更專案資料庫或 JSON 交換格式。以現有畫布、視角、專案儲存與幾何邊界為主要實作位置；只有批次貼上需要新的整批持久化與歷史操作接縫。規格與計畫先留在 `annotation-canvas-interactions` 分支；程式與驗收完成後上傳 GitHub Draft PR，使用者明確確認後才另行合併 `main`。

## Testing Decisions

- 以使用者可觀察的畫面、標註幾何、持久化資料與 Undo/Redo 結果驗收；不以特定私有函式或控制項存在作為唯一判據。優先沿用畫布／主視窗接線、視角、SEG 幾何及專案儲存整合測試縫，新增批次貼上的儲存接縫即可。
- 畫布測試覆蓋各工具指標與實際寬度、不同縮放倍率及 DPI、畫筆 3px 路徑與 8px 實心起點、矩形／圓形固定 40% 預覽在結果透明度 0／40／100% 下不變、選中工具與類別的視覺狀態。
- SEG 幾何測試以填色遮罩比較筆刷折返、回到起點、自交、單擊圓點、圓滑端點、靠邊中心限制、橡皮擦單擊及洞，確認未碰到的圈內不自動填滿，儲存／重開及 JSON 往返保持結果。
- 框選測試覆蓋 OBD、SEG 複雜多邊形及洞、筆畫寬度、部分重疊、空白拖曳、控制點與物件上拖曳、一般框選取代與 Ctrl+框選聯集，以及既有 Ctrl+點選行為。
- 視角與快捷鍵測試覆蓋兩軸捲軸是否只在超出時出現、捲軸與右鍵／滾輪／縮放同步、邊界夾限、圖片放得下時置中、切圖與切頁、標註工具下 `F`、未完成操作按 `F`、文字焦點、`Z`／`X` 範圍及繪製中寬度鎖定。
- 複製貼上測試覆蓋 OBD 與 SEG、同圖重疊複本、跨圖與多圖、來源圖包含在目標、每圖部分物件超界靜默略過、快照與來源後續變更、類別刪除 Toast、新身分與層級、貼後選取、單次 Undo/Redo、意外寫入失敗的原子性、重開專案及 JSON 往返。
- 隱藏標註測試覆蓋 `[` 與勾選同步、切圖與切標註集、既有物件不命中、新增預覽可見但提交後隱藏、重新開啟預設顯示、資料及匯出不受影響。
- 旋轉測試覆蓋多選矩形、橢圓、筆畫與有洞區域各自中心和相同角度、拖曳期間旋轉外框與控制點、任一區域超界時整組保持最後合法狀態、放開後 0 度外接矩形、單物件縮放、Undo/Redo 與重新開啟。
- 執行 Release x64 建置與非互動測試；Windows 實際鍵鼠驗收另外檢查 1366×768、1920×1080、100%～200% DPI、視覺可辨識與連續 SEG 操作回應。CI 通過不取代桌面驗收。

## Out of Scope

- CLA 標註的區塊複製貼上、OBD 旋轉、群組縮放，以及跨標註集貼上或類別自動映射。
- 寫入 Windows 系統剪貼簿、跨應用程式貼上或關閉程式後保留複製快照。
- 把顯示標註狀態、目前工具或落筆類別存入專案或 JSON；改變既有 JSON 結構。
- 圖片尺寸小於目前筆寬的專用提示或自動縮小筆頭。
- 在使用者完成桌面驗收及明確指示前合併 `main`。

## Further Notes

- 本規格補充既有標註介面與圖片匯入增量規格。先前將多選旋轉列為範圍外的決定由本規格取代；其他未衝突的資料、幾何及互動契約持續適用。
- SEG 新繪製同類別面積重疊仍依既有規則聯集；複製貼上產生獨立標註複本，是另一種操作語意。
- 既有非文字輸入 `F` 接線已涵蓋標註頁；實作時先重現實際失效情境，再作最小修正。
