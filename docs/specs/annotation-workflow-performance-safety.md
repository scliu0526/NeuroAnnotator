# 標註工作流程安全與效能增量規格

## Problem Statement

Neurocle 目前可同時啟動多個應用程式執行個體；同一專案雖另有檔案鎖，使用者仍可能誤開多份程式。標註頁左側圖片清單缺少批次清除入口，各頁清單欄位也未依工作情境清楚區分。

SEG 區域經擦除形成空洞後，純平移仍會重新解析並建立空洞橋接，可能顯示「無法建立合法的空洞連線，這次 SEG 修改已取消；原標註與 Undo 歷史未變更。」。同一路徑在拖曳放開後執行不必要的高成本幾何搜尋與逐點寫入，使大量點位或多選移動卡住數秒。切換圖片時又可能重複解碼圖片、載入兩個畫布及刷新整份摘要，且每次換圖都會把畫布視角重設為適合視窗。

## Solution

同一 Windows 登入工作階段只允許一個 Neurocle 執行個體；第二次啟動顯示提示後退出。圖片清單依頁面與標註集型別顯示必要欄位，並在標註頁、資料集分配頁及完成／匯出頁提供一致、保留多選且有確認步驟的清除選單。

純平移 SEG 區域時，全部點位與既有空洞橋接依同一整數位移移動，不重新解析或建立橋接。拖曳預覽以共同位移呈現，提交以平移命令更新持久化資料及 Undo/Redo。

切圖時分離目前圖片載入與整份摘要刷新，避免兩個畫布重複解碼，並以有界快取保留最近三張圖片。新圖片完成前繼續顯示舊圖片但停用畫布標註操作。新舊圖片尺寸相同時保留縮放比例與位置；尺寸不同時才重新適合視窗。

## User Stories

1. 身為 Neurocle 使用者，我希望同一 Windows 登入工作階段只能開啟一份程式，以免在多個視窗間誤操作。
2. 身為重複啟動程式的使用者，我希望看到程式已在執行的提示，以便理解第二次啟動為何結束。
3. 身為不同 Windows 工作階段的使用者，我希望各工作階段可各自執行一份程式，以便互不阻擋。
4. 身為圖片管理使用者，我希望圖片頁左側清單顯示序號、檔名、資料集與 Retest，以便瀏覽時掌握分配狀態。
5. 身為 CLA 使用者，我希望標註相關頁面顯示類別但不顯示冗餘數量，以便快速辨識指派。
6. 身為 OBD 或 SEG 使用者，我希望相關頁面顯示類別與標註數量，以便辨識空圖與密集圖片。
7. 身為完成／匯出使用者，我希望匯出前仍看見類別與標註數量，以便確認輸出範圍。
8. 身為標註使用者，我希望在已選取列上按右鍵時看見清除命令，以便批次整理。
9. 身為多選使用者，我希望右鍵不改變既有選取，以免批次範圍被意外縮小。
10. 身為多選使用者，我希望選單顯示已選取圖片數量，以便確認影響範圍。
11. 身為清單使用者，我希望在未選取列或空白區按右鍵時不開啟選單，以免目標不明。
12. 身為圖片頁使用者，我希望右鍵不提供清除命令，以免在看不到標註集時修改資料。
13. 身為資料集分配使用者，我希望兩個清除選單使用相同右鍵規則，以便操作一致。
14. 身為批次整理使用者，我希望可清除所選圖片的 Retest，以便移除重測旗標。
15. 身為批次整理使用者，我希望可清除所選圖片的類別或標註，以便移除目前標註集成果。
16. 身為批次整理使用者，我希望可將所選圖片的資料集狀態清為未分配，以便重新安排。
17. 身為謹慎的使用者，我希望三種清除命令都先顯示命令、標註集與圖片數量，以免誤清資料。
18. 身為取消確認的使用者，我希望資料與 Undo/Redo 完全不變，以便安全離開。
19. 身為對已清空圖片再次執行命令的使用者，我希望操作無變更結束且不產生空白歷史。
20. 身為 SEG 使用者，我希望擦除形成空洞後仍能移動該區域，以便繼續調整位置。
21. 身為 SEG 使用者，我希望純平移保留原點序與空洞橋接，以免移動改寫不相關幾何。
22. 身為 SEG 使用者，我希望移動不再出現無法建立合法空洞連線的訊息，以便有效操作不被取消。
23. 身為多選 SEG 使用者，我希望全部區域依共同位移移動並維持相對位置，以便整組調整。
24. 身為靠近圖片邊界移動的使用者，我希望任一區域將越界時仍限制整組移動，以便幾何合法。
25. 身為使用 Undo 的使用者，我希望一次拖曳或連續方向鍵移動形成單一歷史操作，以便容易復原。
26. 身為需要流暢拖曳的使用者，我希望 10 個各約 17,000 點的區域仍能順暢預覽。
27. 身為完成拖曳的使用者，我希望放開後 500 ms 內完成保存、歷史與畫面更新。
28. 身為逐張標註的使用者，我希望切圖不重複解碼或查詢整份摘要，以便新圖片迅速出現。
29. 身為首次查看圖片的使用者，我希望固定案例在 1 秒內完成冷載入。
30. 身為往返最近圖片的使用者，我希望最近三張圖片在 500 ms 內完成暖載入。
31. 身為快速連續切圖的使用者，我希望只顯示最後選取圖片，以免過期結果閃回。
32. 身為等待新圖片的使用者，我希望舊圖片維持顯示直到新圖片準備完成，以免畫布空白。
33. 身為等待新圖片的標註使用者，我希望舊圖片只供顯示且無法編輯，以免資料錯置。
34. 身為在相同尺寸圖片間切換的使用者，我希望縮放與位置完全保持，以便比較相同區域。
35. 身為切換到不同尺寸圖片的使用者，我希望新圖片自動適合視窗，以便看見完整內容。
36. 身為圖片頁與標註頁往返的使用者，我希望兩頁共享圖片與畫布視角，以便繼續查看同一處。
37. 身為長時間瀏覽的使用者，我希望快取有固定上限，以免瀏覽 100 張後記憶體持續成長。
38. 身為離線桌面使用者，我希望改善不改變 JSON 或引入網路服務，以便維持既有契約。
39. 身為專案使用者，我希望失敗的 SEG 操作不改變標註或歷史，以便資料一致。
40. 身為審查者，我希望硬性效能門檻與回歸證據在 PR 中可追查，以便合併前判斷完成度。
41. 身為 OBD 或 SEG 使用者，我希望零標註圖片的標註數量欄留白，以免大量 `0` 干擾掃讀。
42. 身為鍵盤操作使用者，我希望左右方向鍵與上下方向鍵同樣可靠地移動所選標註，不受目前控制項焦點影響。
43. 身為 Shift 多選使用者，我希望完成範圍選取後可立即使用切分所選，以便批次分配資料集。
44. 身為舊版 JSON 使用者，我希望無法重新解析橋接的既有 SEG 仍可整體移動、旋轉與縮放，以便繼續編輯歷史資料。
45. 身為多空洞 SEG 使用者，我希望改變類別不重建幾何，以免孔洞數增加時完成操作變慢。
46. 身為多空洞 SEG 使用者，我希望新增一個孔洞只增量評估必要橋接候選，仍產生全域最短合法網路且在 500 ms 內完成。

## Implementation Decisions

- 單例範圍是目前 Windows 登入工作階段；第二份程序只提示並結束，不啟用第一份視窗。
- 單例閘門位於主視窗及啟動診斷事件之前，第一份程序持有到訊息迴圈結束。
- 圖片頁顯示序號、檔名、資料集及 Retest；標註頁的 CLA 顯示類別，OBD、SEG 顯示類別及標註數量；OBD、SEG 的零數量顯示留白。
- 資料集分配頁顯示資料集與 Retest；完成／匯出頁同時顯示適用的類別、標註數量、資料集及 Retest。標註、資料集分配及完成／匯出頁提供清除選單，圖片頁不提供。
- 右鍵命中已選取列時才開啟選單且不得改變選取；選單固定顯示選取數量與三個命令。
- 清除 Retest、類別及資料集都必須確認。沒有實際差異時不得新增空白歷史。
- CLA 清除不建立 Undo/Redo；OBD、SEG、Retest 與資料集沿用既有歷史契約。
- 純平移以區域識別碼及共同整數位移表示，不透過一般幾何更新重新橋接。
- 純平移保留身分、類別、型別、點序、橋接、群組相對順序及移動後置頂規則。
- 改變輪廓相對幾何的操作仍使用既有 Clipper2、Non-Zero Winding 與合法橋接規則。
- 拖曳預覽保存共同位移，不在每幀複製全部點位；正式幾何與 JSON 座標不得近似。
- 純平移持久化使用座標增量更新；Undo/Redo 以相反位移重播同一完成操作。
- 整體旋轉或縮放在整數化後驗證既有空洞橋接；仍合法時保留點序，失效時才依既有規則重建，避免空洞數增加時產生不成比例的延遲。
- 舊版匯入路徑若無法重新解析橋接，但整體變形仍保持相同點數與點序，保存變形後點序而不取消操作；一般任意幾何修改仍須建立合法橋接。
- 只改變 SEG 類別或層級時僅更新中繼資料，不解析、刪除或重寫點位。
- 新增單一孔洞時保留仍合法的既有候選，並依輪廓大小使用精確線段或外框距離下界，逐步計算可能改善 Kruskal 結果的候選；結果仍是全域最短合法連通樹。
- 四個方向鍵都先進入標註快捷鍵路由；文字輸入仍保留原生方向鍵。Shift 滑鼠多選完成時重新取樣最終選取集合。
- 畫布已確認不超出圖片邊界的純平移提交不在資料層重複掃描全部點位；其他資料層呼叫仍執行完整邊界檢查。
- 專案資料庫通過 schema 驗證後使用 SQLite WAL；既有 Save checkpoint 契約不變，且不改變資料庫 schema 或 JSON。
- 圖片選取、目前圖片標註載入及全清單摘要刷新分為不同責任；單純切圖不掃描全部摘要。
- 同一圖片不得由兩個畫布重複從磁碟解碼；快取至少保留最近三張並有固定上限。
- 新圖片完成前保留舊圖片、不顯示提示，並停用繪製、選取、移動、刪除及標註快捷鍵。
- 快速切圖取消過期要求；只有最後選取圖片可套用圖片、標註及畫布視角。
- 新舊圖片寬高完全相同時保留倍率與原點；任一不同時適合視窗。邊界規則不變。
- 不變更 SQLite schema、JSON、專案鎖、標註聯集或專案工作佇列。
- 硬性門檻未通過時不得宣稱完成或建立待合併 PR。

## Testing Decisions

- 測試可觀察行為、資料結果、歷史、畫布狀態與時間，不測特定私有實作。
- 啟動接縫驗證第一份取得、第二份拒絕、釋放後可重啟及工作階段範圍。
- WinForms 互動接縫驗證欄位矩陣、右鍵命中、多選、數量、確認、載入鎖定及視角。
- 專案儲存整合接縫驗證擦除形成洞後的純平移、點序、橋接、層級、歷史、重開及 JSON。
- 畫布事件接縫以滑鼠與鍵盤驗證單選、多選、邊界及載入期間不提交。
- 圖片載入接縫驗證不重複解碼、最近三張快取、淘汰、快速取消、缺圖與資源釋放。
- 相同尺寸切圖精確保留 Zoom、Origin；不同尺寸重新適合視窗，並覆蓋冷／暖／快速切換。
- SEG 固定壓力為 10 個各約 17,000 點：平均至少 60 FPS、p95 ≤ 16.7 ms、最大單幀 ≤ 50 ms、提交 ≤ 500 ms。
- 大量點位與大量空洞分開驗證；大量空洞案例以 64 個洞和同總點數單一區塊比較移動、旋轉、縮放，兩者皆須符合相同幀時間與 500 ms 提交門檻，且空洞、橋接、Undo/Redo 與重開結果保持正確。
- 另以 64 個既有孔洞新增第 65 個孔洞，並記錄相同點數單一區塊新增孔洞作為對照；兩者皆須在 500 ms 內完成。只改變類別須在 100 ms 內完成並保持點序、Undo/Redo 與重開結果。
- 使用實際 316 點 class3 輪廓的可攜式測試驗證平移、整體變形及改類別，不依賴外部 JSON 路徑。
- 圖片案例包含 1920×1080、5120×2880、PNG、JPEG、無標註、密集 OBD、約 17,000 點 SEG；冷載入 ≤ 1 秒，最近三張暖載入 ≤ 500 ms。
- 連續瀏覽 100 張後，工作集與 GDI 物件不得隨次數持續成長。
- 交付前執行 Release x64、全部非互動測試、手動效能門檻、Designer 與 100%、150%、200% DPI。

## Out of Scope

- 跨使用者或工作階段的整台電腦單例。
- 第二次啟動時啟用既有主視窗。
- 在圖片頁提供清除命令。
- 為 CLA 定義 0／1 標註數量。
- 為每張圖片持久化獨立畫布視角。
- 對任意圖片、任意幾何或其他硬體保證相同效能。
- 無上限快取所有曾瀏覽圖片。
- 對沒有可驗證既有最小生成樹的任意多輪廓修改改變完整橋接規則。
- 改變 JSON、資料庫 schema、專案鎖、工作佇列或離線邊界。
- 未經使用者批准合併 `main`。

## Further Notes

- 現行畫布設定新圖片尺寸時直接適合視窗；本規格改為依新舊尺寸決定保留視角或適配。
- 現行 SEG 更新對所有多邊形無條件重新橋接；本規格以明確純平移命令縮小重建範圍。
- 現行選圖要求兩個畫布各自載入並刷新全圖片摘要；正式修正先以分段量測確認成本。
- 時間門檻只對指定驗收電腦及固定合成案例成立。
- 所有修改在 `annotation-workflow-performance-safety` 分支完成；使用者明確批准前不得合併。
