# Neurocle AI 標記工具正式規格

## Problem Statement

現有資料包含 CLA、OBD、SEG 三類圖片與 JSON 標記範例，但缺少一套可在指定 Windows 電腦上完全離線運作、能管理同一圖片池的多份標註成果、支援複雜 SEG 幾何編輯並可靠輸出相容 JSON 的桌面工具。第一版的目標是完成可驗證的人工標記工作流，不包含模型訓練或推論。

## Solution

建立 C#、.NET Framework 4.7.2、WinForms、x64 的可攜式桌面應用程式。專案使用 SQLite 保存結構化狀態，圖片複製到受管理的本機目錄。使用者可匯入及瀏覽圖片、建立多份 CLA／OBD／SEG 標註集、進行各模式標記、分配資料集、設定 Retest，並將單一標註集 JSON 或圖片 ZIP 分開匯出。

SEG 使用經原型驗證的 Clipper2 整數幾何核心及 Non-Zero Winding 填色規則，以支援同類別聯集、局部擦除、洞、自交、旋轉與分裂。所有重要行為在領域／應用用例、幾何、序列化與持久化邊界自動測試，WinForms 本身只保留必要的接線與端對端冒煙測試。

標註介面、SEG 完成效能與最近合法空洞橋接的後續修訂以[增量規格](annotation-ui-seg-performance.md)為準。

## User Stories

1. 身為使用者，我可以建立、開啟、儲存與另存專案，讓圖片與多份標註集在重新啟動後仍一致。
2. 身為使用者，我可以從多選檔案或資料夾匯入 PNG、JPG、JPEG、BMP，並在資料夾模式決定是否包含子資料夾。
3. 身為使用者，我可以在匯入取消或部分檔案失敗時保留已成功項目，並看到成功、未完成與失敗數量及原因。
4. 身為使用者，我可以在最多 10,000 張圖片的虛擬化文字清單中依連續序號或檔名自然排序、搜尋及篩選，點擊後預覽圖片。
5. 身為使用者，我可以在共享圖片池上建立多個 CLA、OBD、SEG 標註集，自行命名並從型別加名稱的下拉選單切換。
6. 身為使用者，我可以新增、重新命名、刪除類別及修改顏色；每個新標註集預設有 `class1`，且永遠至少保留一個類別。
7. 身為使用者，我可以在 CLA 對每張圖片指定零或一個類別，改選類別時取代原值。
8. 身為使用者，我可以在 OBD 以左鍵拖曳建立多個矩形框，並以選取、拖曳及八個控制點移動或調整大小。
9. 身為使用者，我可以在 SEG 使用矩形、圓形、封閉畫筆、塗抹筆刷及兩點式線型建立區域，並使用橡皮擦只移除目前類別中實際塗過的面積。
10. 身為使用者，我可以選取 SEG 區域後移動、自由旋轉，或以軸對齊外接矩形的八個控制點非等比例縮放。
11. 身為使用者，我可以按住 Ctrl 多選物件後一起移動、刪除或改類別；縮放與旋轉只作用於我操作控制點的主要物件。
12. 身為使用者，我可以透過透明填色看見不同類別在相同像素的重疊，並以預設 40% 的透明度滑桿調整 OBD 填色及 SEG 填色、筆刷與線型的顯示；切換標註集或重開專案時回到預設值。
13. 身為使用者，我在新繪製區域與同類別區域發生面積重疊時會得到聯集結果；如果只是移動、縮放、旋轉或改類別造成重疊，物件仍保持獨立。
14. 身為使用者，我可以使用 Ctrl+Z、Ctrl+Y 或 Ctrl+Shift+Z 跨圖片及頁面復原或重做目前標註集最近的操作。
15. 身為使用者，我可以將圖片在各標註集中獨立設為 train、test、未分配或 not_used，並以 Retest 按鈕及右鍵選單批次設定或清除 Retest、類別與資料集狀態。
16. 身為使用者，我可以輸入相連的 train/test 百分比並自動切分；系統優先滿足每類 train 至少 10 張與整體 test 至少 3 張，再逼近比例與類別平衡。
17. 身為使用者，我可以在條件無法滿足時看到警告，但仍能保留切分並匯出。
18. 身為使用者，我可以只選擇一份標註集匯出 JSON；未標註但已分配的圖片仍輸出空類別，缺失圖片則略過。
19. 身為使用者，我可以與 JSON 分開，將選取圖片或全部圖片匯出成根目錄扁平的 ZIP，且不修改專案內原檔。
20. 身為使用者，我可以匯入一份嚴格驗證的參考 JSON 成為新標註集；任何必要資料錯誤都使整批不寫入。
21. 身為使用者，我可以在圖片缺失時以 SHA-256 重新連結完全相同內容，或永久移除該圖片及其所有標註。
22. 身為使用者，我可以檢視、建立與還原資料庫備份；每日首次開啟及結構遷移前會自動備份並保留最近五份。
23. 身為使用者，我可以在 1% 到 400% 縮放、使用指定倍率或適合視窗，並以滾輪、Shift+滾輪及 Space+左鍵平移畫布。
24. 身為使用者，我可以在繁體中文介面工作；產品字串結構允許未來新增語言，而不需改寫業務邏輯。
25. 身為使用者，我可以在斷網環境從 ZIP 解壓後直接執行，且應用程式不會要求登入、遙測或線上更新。

## Implementation Decisions

### 平台與部署

- 目標為 Windows 10/11 x64、.NET Framework 4.7.2 WinForms、C#。
- 發佈物為包含全部執行相依項目的可攜式 ZIP；不建立安裝程式。
- 第一版只顯示繁體中文；所有 UI 字串置於資源檔，以便後續新增語言。
- 啟動時支援 100%、125%、150%、175%、200% DPI；最低驗收解析度為 1366×768。
- 正式執行完全離線；CI 可連網還原套件。

### 專案與圖片

- SQLite 資料庫與受管理的扁平圖片目錄共同構成專案；只允許本機固定磁碟。
- 圖片匯入專案時複製。撞名自動加後綴，同時保留原始檔名。
- 匯入批次以檔名自然排序後配置序號；刪除後序號向前遞補，新圖片接續 N+1。所有關聯使用不可變內部識別碼。
- 每張圖片保存 SHA-256。忽略 EXIF 旋轉並以原始像素矩陣顯示及標記。
- 單檔上限 100 MB、寬高各 10,000 像素、總像素 100,000,000；專案上限 10,000 張。
- 匯入期間允許對既有圖片進行單張標註，但停用全域與批次操作。
- 缺失圖片保留資料以供重新連結；匯出時略過。永久移除後不保留任何相關標註。
- 同一專案禁止同時開啟兩次。

### 標註集與類別

- 圖片池共享；標註、類別、資料集狀態、Retest 與 Undo/Redo 由標註集隔離。
- 標註集名稱允許重複，內部以不可變識別碼區分；選單只顯示型別與名稱。此選擇接受名稱重複造成誤選的風險。
- 標註集支援建立、重新命名、刪除，不提供複製。刪除時必須輸入完整且區分大小寫的名稱，且不可復原。
- 類別名稱去除首尾空白後不得為空；同一標註集內區分大小寫且不可完全重複。刪除使用中類別會連帶刪除其所有標註，確認後可 Undo；不可刪除最後一個類別。
- 顏色建立時自動指定且可修改；匯入值原樣保留，包括 `-custom`。

### 畫布與選取

- 固定倍率為 10%、50%、75%、100%、125%、150%、200% 及適合視窗；連續倍率範圍為 1%～400%。Ctrl+滾輪以游標為中心縮放。
- 滾輪垂直移動，Shift+滾輪水平移動，Space+左鍵自由平移。
- 圖片與標註頁共用目前圖片、倍率與平移位置；實際倍率即時顯示，非文字輸入狀態可按 F 適合視窗。各軸平移不得越過圖片邊界；縮放後不大於視窗的軸置中且不可平移。
- 切換圖片、標註集或頁面時，未完成形狀直接捨棄。
- 標註頁非文字輸入狀態的 Ctrl+A 選取目前圖片與標註集的全部 OBD／SEG 物件；Ctrl+左鍵多選只在選取模式生效。OBD／SEG 標註集進入時預設選取模式。
- OBD 與 SEG 點擊選取最上層物件。完全被遮住的下層物件必須先移開上層才可選；可見的下層被選取時暫時置頂，未修改即取消則恢復原層級，任何編輯後永久置頂。
- 多選移動時，任一物件外接矩形碰到圖片邊界即限制整組繼續向該方向移動；被移動項目整組置頂並保留彼此順序。

### CLA 與 OBD

- CLA 每張圖片零或一個類別；點擊其他類別直接取代。
- OBD 每張圖片可有多個帶類別的軸對齊 `Rect`。左鍵按住拖曳建立，以八控制點縮放，不支援旋轉。
- OBD 顯示透明填色、類別色外框與類別名稱；選取後點擊類別可改類別。

### SEG 幾何

- `Rect` 以左上角 `x`,`y`,`width`,`height` 表示；`Ellipse` 以中心 `x`,`y`,`radiusx`,`radiusy` 表示；線與筆刷為 `PolyLine`；封閉區域使用格式指定的 `PolyGon` 拼字。
- 矩形及橢圓為按下、拖曳、放開；線型為第一次左鍵設定起點、移動預覽、第二次左鍵設定終點，Esc 取消。
- 畫筆可逐點點擊或按住左鍵自由畫。只有回到起點且完成放開才封閉；自由畫穿過起點但未放開不完成。閉合命中半徑為螢幕 8 像素並提供高亮提示；自由畫每移動螢幕 2 像素記錄新點，不做完成後簡化。
- 筆刷、線型、橡皮擦共用一個原圖 1～100 整數像素寬度，預設 15，單次程式工作階段記住上次值。筆刷與線型的預覽軌跡寬度必須與完成結果相同。
- 完成的矩形至少 1×1；線至少兩個不同點且寬度至少 1；新封閉區域至少三個不同且不共線的點。
- 區域可移動、自由旋轉、以軸對齊外接矩形八控制點非等比例縮放。互動預覽可用小數，操作完成以四捨五入保存整數。
- 物件外接矩形不得超出圖片；碰到邊界後不可繼續向外移動、縮放或旋轉。
- 填色規則為 Non-Zero Winding，接受自交、重複點及同區域多次繞行。
- 新繪製的同類別區域只有在面積實際重疊時聯集；邊或角接觸不合併。既有物件的移動、縮放、旋轉、改類別不觸發聯集。不同類別可同像素重疊。
- 橡皮擦只對目前選取類別下的所有相交區域做局部差集；其他類別不變。殘留的連通分量各自成為新區域，微小碎片不自動刪除。
- 洞以單一 `PolyGon` 的橋接邊與相反繞行方向表示。新生成或幾何編輯後重新生成的洞選擇內外輪廓邊段間最短的合法連線，必要時插入端點；連線不得穿出標註實體或穿過其他洞。旋轉或擦除後，矩形、橢圓與線型可轉為一個或多個 `PolyGon`。
- 未修改的匯入路徑保留原始點序與重複點；一經幾何編輯，只要求填色面積、洞、分量與類別語意等價。
- 正式幾何實作採 Clipper2 的 64 位整數路徑。正式 SEG 功能開始前先完成可拋棄的風險原型。

### Undo、儲存、備份與日誌

- 每個標註集維持全域時間順序的 Undo/Redo，可跨圖片及頁面；切換標註集時保留，關閉專案後清空且不持久化。
- 每個標註集最多保留 100 個動作或 512 MiB，任一限制先到即從最舊動作淘汰。Undo/Redo 後立即自動儲存。
- 永久刪除圖片與標註集不可 Undo。
- 完成操作後混合式自動儲存，並提供儲存與另存新檔。
- 每日第一次開啟及資料庫結構遷移前建立資料庫備份，僅保留最近五份；備份不含圖片。提供備份管理、還原及損毀時提示；還原前先備份目前資料庫。
- 日誌位於 `%LocalAppData%\Neurocle\Logs\YYYY-MM-DD.log`，每日一檔且永不自動刪除、壓縮或輪替。不得記錄圖片內容或完整座標；介面顯示占用空間並可開啟資料夾。

### 資料集分配

- 各標註集獨立保存 train、test、未分配、not_used；test 同時作為驗證集。Retest 是獨立 0/1 旗標，預設 0。
- train 與 test 是相連的 1～99 整數百分比，預設 80/20；任一變更使另一值等於 100 減去輸入值。
- 每次自動切分重新隨機，不保存種子，並覆寫所有可用圖片的四種資料集狀態，但不改 Retest。缺失圖片維持原狀。
- 三種模式都以「圖片是否含該類別」做多標籤分層，不使用物件數或面積。OBD、SEG 空標註與 CLA 未標註圖片在已標註圖片後分配，用來逼近整體比例。
- 優先順序為：能做到時每類 train 至少 10 張；整體 test 至少 3 張；再逼近整體比例與類別平衡。test 不要求每個類別都出現。無法滿足時顯示警告但不阻止切分或匯出。
- 已分配但無標註的 OBD／SEG 圖片是有效負樣本；CLA 可輸出空類別。第一版不執行訓練。

### JSON 匯入與匯出

- JSON 使用 UTF-8，欄位及值遵循既有樣本，包括 `label_type`、`source`、`time`、`version`、`classes`、`data`、`fileName`、`set`、`classLabel`、`regionLabel`、`retestset`、`rotation_angle`、`width`、`height`。
- 匯出一次只選一個標註集，包含所有可用專案圖片。資料集狀態映射為 `train`、`test`、空字串、`not_used`；CLA 未標註輸出空 `classLabel`。
- `source` 為 `labelset`，`version` 為 `4.5.2.2`，`time` 為 UTC 匯出時間，`rotation_angle` 固定為 0。座標原點在左上，x 向右，y 向下。
- 匯入 JSON 會建立新標註集，JSON 未列出的現有專案圖片加入空資料。JSON 指向不存在圖片、映射到多張圖片、必要欄位或座標無效、未知區域型別、非零 `rotation_angle` 時整批拒絕且不寫入。
- 額外未知欄位顯示警告；使用者若繼續，未知欄位不保存。提供的 Retest 值照原值匯入；新補入的空圖片為 0。
- 已存在的輸出檔名或資料夾名稱自動使用 `(1)`、`(2)` 後綴，不詢問覆寫。

### 圖片匯出

- 圖片匯出與 JSON 匯出是兩個獨立功能。
- 可匯出選取圖片或全部圖片；「全部」永遠代表整個專案，不受目前搜尋或篩選影響。
- 輸出為 ZIP，圖片平放在 ZIP 根目錄，名稱採專案目前受管理檔名，內容不轉檔、不縮放。

### 清單與導覽

- 主流程分為圖片、標註、資料集分配、完成／匯出頁面，可自由切換。
- 圖片清單只顯示文字並虛擬化；支援檔名搜尋，以及資料集狀態、類別、是否有標註、Retest 篩選。
- 預設依序號遞增；序號及檔名標頭可切換遞增／遞減。
- 圖片與標註頁左側常駐同一圖片清單；非文字輸入狀態按上下鍵依目前可見順序切圖。搜尋或篩選排除目前圖片時，畫布保留原圖，直到使用者選擇結果或按上下鍵。
- 標註工具依選定標註集型別在圖像右側顯示；工具以圖示及滑鼠停留提示呈現。新增類別位於類別清單上方，縮放控制位於圖像上方。正常視窗下兩頁圖片顯示區同尺寸，且比原標註畫布至少高約 25%。
- 成功建立 CLA、OBD 或 SEG 標註集後自動切換至新標註集。資料集分配頁在 OBD／SEG 型別顯示目前標註集每張圖的實際標註物件數。

### 相依套件與授權

- 幾何使用 Clipper2；資料庫使用 Microsoft.Data.Sqlite 及其 x64 SQLite 原生元件；JSON 使用 Newtonsoft.Json；測試使用 MSTest/TestFX。
- 接受 MIT、BSD、Apache-2.0、Boost-1.0 與 SQLite public domain；散布套件需包含相依授權聲明。
- JSON 反序列化不得啟用任意型別建立。

## Testing Decisions

- 最高價值測試縫是「應用用例／領域命令」：以 SQLite 交易工作單元執行匯入、編輯、切分、刪除及匯出，時鐘、亂數與檔案系統由可替換介面控制。大多數產品規則在此層自動驗證，而非透過滑鼠測試。
- 第二測試縫是獨立幾何契約：對 Clipper2 封裝層驗證聯集、差集、洞、Non-Zero、自交、筆刷膨脹、變形、邊界、四捨五入與效能。
- 第三測試縫是 JSON 序列化邊界：以提供的 CLA、OBD、SEG 及旋轉、擦除、自交範例做匯入／匯出與語意往返測試。
- 第四測試縫是薄 WinForms 接線：只以 Windows UI Automation 驗證啟動、頁面切換、基本輸入與錯誤顯示；精確幾何不依賴 UI 自動化判定。
- CI 固定使用 GitHub Actions `windows-2022`，建置 x64 .NET Framework 4.7.2 並執行所有非互動測試。UI Automation、DPI、滑鼠操作、效能與斷網流程在指定驗收電腦逐階段執行。
- SEG 原型是進入正式 SEG 階段的硬性閘門。它必須先通過洞、自交、重複點、同類別聯集、橡皮擦分裂、線寬、旋轉、邊界、整數化、約 17,000 點路徑、30 FPS 互動及 Undo 記憶體評估；否則停止並重新決策，不以臨時補丁進入正式實作。
- 效能驗收目標：10,000 筆清單可互動時間不超過 10 秒；切換 5K 圖片不超過 2 秒；一般拖曳／旋轉至少 30 FPS；連續瀏覽 100 張圖片後沒有持續性記憶體成長。
- SEG 畫筆、筆刷完成運算期間介面須持續回應，切圖要求於安全儲存後執行。本次在指定電腦以現有素材及約 17,000 點壓力案例逐筆驗證完成輸入至持久化且可見的時間不超過 1 秒；其他有效案例持續以 1 秒為優化目標，不宣稱未量測情境已通過。
- 圖片限制、部分成功匯入、JSON 原子失敗、缺失圖片、備份還原、專案鎖、Undo 淘汰、隨機切分約束與輸出撞名都必須有自動或明確手動驗收案例。

## Out of Scope

- 模型訓練、驗證執行、推論、自動標記及任何 AI 模型整合。
- 雲端儲存、跨機同步、多人協作、帳號登入、遙測與自動更新。
- 網路磁碟、NAS、雲端同步目錄、USB 或其他可移除磁碟上的專案。
- macOS、Linux、x86 與 ARM。
- 標註集複製、同一個 JSON 同時匯出多個標註集，以及圖片與 JSON 合併為同一匯出包。
- 影像轉檔、縮放、EXIF 自動旋轉與圖片內容編輯。
- 第一版以固定種子重現相同自動切分。
