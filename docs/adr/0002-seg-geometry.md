# ADR-0002：SEG 採整數多邊形、Non-Zero Winding 與 Clipper2

## 狀態

Accepted

## 背景

參考 JSON 證明 SEG 需要自交、重複點、洞、橡皮擦局部差集、同類別聯集、筆刷線寬及旋轉後多邊形。這些行為超出 WinForms 基本繪圖物件的可靠布林運算能力。

## 決策

SEG 幾何核心使用 Clipper2 的 64 位整數路徑與 Non-Zero Winding 規則。互動預覽可保留小數，但完成操作時以四捨五入轉為整數座標。矩形、橢圓、筆刷、畫筆、線型與橡皮擦最終都可轉為可做聯集或差集的路徑。

新繪製區域與同類別既有區域發生實際面積重疊時聯集；僅接觸邊或角不合併。移動、縮放、旋轉或改類別造成的重疊不自動聯集。洞以單一 `PolyGon` 的橋接路徑與相反繞行方向輸出。

對新生成或幾何編輯後重新生成的洞，橋接端點可插入內外輪廓的邊段中途，選擇不穿出標註實體、不穿越其他洞的最短合法連線；等距時採穩定選擇。這比固定使用輪廓首點更符合最近邊緣的標註語意。未修改的匯入路徑保持原點序，不因新橋接規則重寫。

純平移不改變輪廓之間的相對幾何、合法性或橋接距離，因此全部點位與既有橋接只套用相同整數位移，不重新解析或建立橋接。整體縮放或旋轉完成整數化後，必須重新解析並驗證既有橋接網路；若每條橋接仍合法、互不交叉且仍連通全部輪廓，可保留既有點序，否則依前述最短合法連線規則重建。擦除及其他任意幾何編輯仍依前述規則重新產生合法橋接。

新增單一孔洞且舊輪廓未變時，保留仍合法的既有候選邊，並依所有輪廓配對的安全距離下界逐步計算可能改善 Kruskal 結果的候選；小輪廓配對使用精確線段距離，大量點位配對使用外框距離，避免下界本身成為瓶頸。當已知候選已形成連通樹，且其最大選取權重小於下一條尚未計算候選的距離下界時，剩餘候選不可能改善最小生成樹，可停止搜尋；這不改變全域最短、合法性或穩定排序契約。只改變類別或層級不屬於幾何編輯，不重新橋接或重寫點位。

舊版匯入路徑可能可依 Non-Zero Winding 顯示，卻無法依現行橋接分析還原。這類路徑做整體旋轉或縮放且維持相同點數與點序時，若現行重建失敗則保留變形後點序；一般擦除、新增孔洞或任意點位修改仍必須產生合法橋接，不能使用此相容性退路。

## 理由

- Non-Zero Winding 最接近既有複雜路徑樣本的填色語意。
- 整數核心符合交換格式，也使布林運算較可預測。
- Clipper2 原生支援聯集、差集、偏移與複雜多邊形，比自行實作風險低。

## 後果

- 正式 SEG 開發前必須以拋棄式原型驗證洞、自交、重複點、筆刷膨脹、擦除分裂、旋轉、邊界、效能與記憶體。
- 未修改的匯入路徑要保留原始點序與重複點；經幾何編輯後只保證填色語意等價，不保證逐點相同。
- 純平移要保留原始點序、重複點與橋接，只改變座標；不得以一般幾何更新取代。
- Clipper2 的 Boost-1.0 授權及其授權聲明必須納入散布套件。
