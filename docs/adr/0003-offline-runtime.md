# ADR-0003：應用程式維持完全離線且僅支援本機固定磁碟

## 狀態

Accepted

## 背景

目標環境需要可攜式部署及離線作業。專案資料可能很大，且外部同步、網路中斷或多台機器並行寫入會破壞單機資料一致性假設。

## 決策

正式應用程式不包含雲端、登入、遙測、自動更新或任何必要網路呼叫。專案只能建立在本機固定磁碟，不支援網路磁碟、NAS、雲端同步目錄與可移除磁碟。開發與 GitHub Actions 可以連網取得建置相依套件，但發佈成品必須包含執行所需元件。

## 理由

- 消除網路可用性及遠端服務變更對標記工作的影響。
- 限縮檔案鎖、延遲、同步衝突與中途卸載等失敗模式。
- 讓驗收可在指定電腦上重現。

## 後果

- 使用者自行負責將完整專案複製到其他位置或設備。
- 日誌、資料庫備份與圖片都可能持續占用本機空間；產品必須揭露用量與失敗原因。
- 發佈驗收必須在斷網狀態執行啟動、編輯、重開與匯出流程。
