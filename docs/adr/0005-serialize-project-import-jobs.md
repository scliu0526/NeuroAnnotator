# ADR-0005：同一專案的匯入工作以單一 FIFO 序列執行

圖片檔案、資料夾與標註 JSON 匯入都會寫入同一個開啟中的專案。Neurocle 將每次要求表示為匯入工作，並透過專案範圍的單一 FIFO 逐一執行，不允許平行寫入。這讓順序可見，保留 JSON 原子性與圖片匯入部分成功語意，並在排隊工作仍指向目前專案時阻止切換專案。

## 考慮過的方案

- 平行執行匯入並只依賴資料庫交易。拒絕此方案，因為檔案管理、圖片序號、標註初始化、進度、取消與專案替換跨越單一資料庫交易的邊界。
- 每種匯入各自維護佇列。拒絕此方案，因為不同工作者仍可能同時寫入同一專案，且跨類型順序不明確。
- 一項匯入執行時停用全部匯入入口。拒絕此方案，因為使用者需要在目前工作完成前先準備後續匯入。

## 後果

- 同一時間最多只有一筆匯入工作依加入順序寫入專案。
- 三種匯入共用取消、歷史、關閉與專案生命週期規則；JSON 原子寫入開始後仍不可取消。
- 等待與執行中的工作完成或安全取消前，不得替換目前專案。
