# Neurocle 測試與驗收計畫

## 1. 測試策略

| 測試縫 | 主要責任 | 執行位置 |
|---|---|---|
| 應用用例／領域命令 | 專案交易、匯入、編輯、類別、Undo、切分、刪除、匯出規則 | CI 與本機 |
| 幾何契約 | 聯集、差集、洞、填色、自交、變形、邊界、整數化 | CI 與效能本機 |
| 序列化邊界 | JSON 嚴格驗證、欄位值、round-trip、錯誤原子性 | CI 與本機 |
| SQLite 整合 | 結構版本、交易、鎖、備份、還原、崩潰後一致性 | CI 與本機 |
| WinForms 接線 | 啟動、頁面切換、命令連接、訊息、快捷鍵 | 指定 Windows 電腦 |
| 非功能驗收 | DPI、滑鼠手感、效能、記憶體、斷網與可攜式部署 | 指定 Windows 電腦 |

自動測試以可控制的檔案系統、時鐘與亂數來源建立可重現情境。隨機切分的產品行為不保存種子，但測試可注入固定亂數以驗證約束與不變條件。

## 2. 持續整合門檻

- GitHub Actions 固定 `windows-2022`。
- x64、.NET Framework 4.7.2 Release 建置。
- 執行所有非互動 MSTest；任一失敗即阻止階段驗收。
- 建置可攜式 ZIP，檢查必要 managed assemblies、x64 SQLite 原生檔與授權檔存在。
- UI Automation、DPI、HDD 效能與斷網測試不在 hosted runner 宣告通過，必須在指定電腦執行。

## 3. SEG-PROTOTYPE 硬性案例

- 讀取基準 SEG 範例中的矩形、橢圓、筆刷、封閉畫筆與線型。
- 比對旋轉範例：矩形及橢圓轉 PolyGon，Polyline／PolyGon 更新點，`rotation_angle` 維持 0。
- 比對擦除範例：外圈完整而中央有洞；路徑橋接與相反繞向在 Non-Zero 下顯示正確。
- 驗證左上→右下→右上→左下→左上的自交路徑，以及兩圈方形、8 字與多次交叉路徑。
- 新繪製同類別實際重疊會聯集；只碰邊／角不合併；既有物件變形後重疊不合併。
- 橡皮擦只影響目前類別，差集後每個連通分量獨立，微小碎片保留。
- 未修改匯入路徑逐點相同；修改後以遮罩／填色語意比對，不要求點序相同。
- 操作完成後以四捨五入得到整數，負值與邊界附近數值不得越界。
- 約 17,000 點路徑在一般拖曳／旋轉達至少 30 FPS，並量測 Undo 快照是否能受 512 MiB 限制。

## 4. 功能測試矩陣

### 專案與匯入

- 建立、開啟、手動儲存、完成操作自動儲存、另存新檔、同專案第二實例拒絕。
- PNG/JPG/JPEG/BMP；副檔名大小寫；損壞檔；錯誤副檔名；0 位元檔。
- 100 MB、10,000 寬高、100M 像素的低於／等於／高於邊界。
- 多選檔案、資料夾、不含／包含子目錄、取消、部分成功、撞名、多次匯入。
- 自然排序與序號；刪除中間項目後遞補；新增後接續。
- 新圖片在所有既有標註集均為未分配、空標註、Retest 0。
- 匯入進行中可編輯既有單張，但全域／批次操作被禁用。

### 標註集、類別與隔離

- 三種型別建立與 `class1`；同名標註集不串資料；重新命名不改 ID。
- 刪除標註集輸入錯誤名稱、大小寫不同、正確名稱；刪除後不可 Undo。
- 類別空白、首尾空白、完全重複、大小寫不同、最後一類別、使用中級聯刪除與 Undo。
- 匯入 `-custom` 顏色後保存及再匯出。

### CLA／OBD／SEG 操作

- CLA 指定、取代、清除與未標註匯出。
- OBD 建立、最小尺寸、移動、八控制點、改類別、多選、刪除、層級及邊界。
- SEG 每一工具的開始、完成、Esc、切換時捨棄；閉合半徑與自由畫放開條件。
- SEG 寬度 1、15、100 及超界輸入；每工具工作階段記憶。
- SEG 多選群組移動、主物件單獨縮放／旋轉、邊界阻擋。
- 完全遮蔽不可選；部分可見下層暫時置頂；取消恢復；編輯後永久置頂。
- 透明度預設 40%、調整只影響顯示且不進 JSON。

### Undo／Redo

- 每個標註集隔離、跨圖片／頁面、切換後保留、關閉專案清空。
- Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z；新操作清除 redo 分支。
- 第 101 個動作淘汰最舊；超過 512 MiB 先淘汰；Undo 後自動保存。
- 圖片及標註集永久刪除不進 Undo；類別級聯刪除可 Undo。

### 資料集與 Retest

- 四種狀態、clear set、retest／clear retest、clear class 對多選項目。
- train/test 輸入 1、20、50、80、99 與無效文字／界外值的連動。
- 可滿足與不可滿足的每類 train 10、整體 test 3 情境。
- test 缺少部分類別仍有效；空 OBD/SEG 與未標註 CLA 的比例補足。
- 每次執行可以得到不同結果；Retest 保留；缺失圖片忽略且舊狀態不變。
- 自動切分覆寫原本 train/test/unassigned/not_used，並在動作前清楚告知。

### JSON 與圖片匯出

- 三種型別、所有資料集狀態、空類別、Retest 0/1、UTC、版本、固定 rotation。
- JSON 只匯出選定標註集且包含所有可用圖片，不受清單篩選影響。
- 不存在圖片、重複映射、錯誤尺寸／座標、未知 region、非零 rotation、缺欄位均整批零寫入。
- 未知額外欄位的取消／繼續分支；繼續後未知欄位不保存。
- 匯入 JSON 未列出的專案圖片補空資料。
- 圖片 ZIP 的選取／全部分支、扁平根目錄、內容雜湊不變、撞名 `(n)`。

### 備份、缺失與日誌

- 同日多次開啟只建立一次每日備份；遷移前必備份；第六份淘汰最舊。
- 還原前保存目前 DB；備份不含圖片；還原後缺圖清楚列示。
- 以相同 SHA-256 重新連結成功，不同內容拒絕。
- 每日一個日誌、跨日新檔、永不自動刪除；日誌不含影像資料或完整座標；用量顯示正確。

## 5. 非功能驗收

### 指定環境

- Windows 10 IoT Enterprise LTSC 10.0.19044。
- Intel Core i9-14900、31.7 GiB RAM。
- D 槽 SATA HDD，驗收前記錄可用空間。

### 效能門檻

- 10,000 筆清單：啟動量測到可排序／點選不超過 10 秒。
- 5K 解析度圖片：點選到完整顯示不超過 2 秒。
- 一般 SEG 拖曳／旋轉：連續量測至少 30 FPS。
- 連續瀏覽 100 張：強制完成可回收物件後，工作集不得呈現隨瀏覽次數持續單調成長；若有平台快取，需證明達到穩定上限。

### 相容性與輸入

- Windows 10 與 Windows 11 x64 至少各一次完整冒煙。
- 100%、125%、150%、175%、200% DPI，最低 1366×768。
- 一般滑鼠、滾輪、Shift、Ctrl、Space 及所有快捷鍵。
- 完全斷網後執行建立、匯入、標註、重開、匯出與備份還原。

## 6. 階段驗收證據

每一階段需保存：Release 建置結果、測試報告、失敗案例修正連結、手動驗收清單、效能原始數據、使用的測試素材版本，以及仍存在的純外觀問題。任何功能性缺陷、資料毀損、未解釋的測試失敗或效能門檻失敗，都會阻止進入下一階段。
