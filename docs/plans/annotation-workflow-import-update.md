# 圖片匯入與標註操作增量實施計畫

## 範圍與完成條件

- 以[增量正式規格](../specs/annotation-workflow-import-update.md)為驗收契約。先修正可重現的 SEG 資料錯誤，再做匯入／交換格式及介面變更。
- 後續修改先建立並使用新分支 `annotation-workflow-import-update`，在該分支上傳 GitHub；使用者確認全部修改完成前，不合併到 `main`。
- 每階段都保留可重現案例、測試結果及尚未解決的失敗。最終須通過 Release x64 建置、相關自動測試、JSON／ZIP 往返與 Windows 實際操作驗收。
- 本計畫是後續實作依據；建立文件這一階段不修改程式碼。

## 1. 基線與 SEG 缺陷定位

1. 以小型合成圖片重現畫筆閉環包住既有同類別區域後，舊填色變空白的現象；保存操作前後遮罩、區域數及 JSON。
2. 逐段核對閉合判定、Non-Zero 填色、幾何聯集、洞橋接、儲存與重畫，確認首次出錯的位置。
3. 建立先失敗的回歸案例，再作最小修正；不得以重畫或單純加一個聯集呼叫取代根因分析。

**驗證：** 圈內空白被補上，舊同類別像素無一消失，同類別實際重疊後成一個區域；其他類別保留。部分／完全重疊、洞、自交、只碰邊角、Undo／Redo 及重開專案均符合既有幾何契約。

## 2. 匯入、檔名與顏色交換邊界

1. 在現有匯入流程加入每檔完成／失敗的進度回報，讓 UI 以已處理／總數更新；處理中可取消，保留既有部分成功語意。
2. 新匯入 BMP 於受管理目錄存為真正 PNG，採唯一顯示檔名；其他支援格式保留原格式。保留原 BMP 的重新連結驗證能力，維持不可變圖片 ID 與資料關聯。
3. 讓顏色解析、顯示、儲存、匯入及匯出遵守同一正規化規則；無效 JSON 顏色在資料寫入前整批拒絕。以可控制的亂數測試新類別顏色不與同集現有 RGB 完全相同。

**驗證：** 混合格式匯入、同名轉檔、資料夾匯入、取消與失敗清理、JPEG 位元組不變、BMP 像素與 PNG 編碼、來源 BMP 重新連結、ZIP／JSON 名稱及舊專案不遷移均通過。舊 `.bmp` JSON 名稱不映射新 `.png` 圖片；舊顏色可讀，輸出正規化，無效值零寫入。

## 3. 清單、標註集與選取介面

1. 在標註頁圖片清單加入目前標註集的類別與適用的數量欄，使用批次摘要；提供完整類別清單與數值排序，空白類別固定排最後。
2. 以單一按鈕及同一視窗取得新標註集型別與名稱；資料集分配頁增加下拉選單，與標註頁共用目前標註集。
3. 對每個被選的 OBD／SEG 區塊繪製外接矩形與八控制點，並讓控制點命中只作用於所屬區塊。
4. 讓所有標註及擦除預覽使用目前類別顏色、固定 40% alpha；筆寬與透明度的數值及滑條雙向同步。

**驗證：** 類別／數量於合併、擦除、刪除、Undo／Redo、JSON 匯入及切換標註集後更新；CLA 不顯示數量。10,000 張清單保持既有可排序／可點選門檻。重疊控制點、群組移動、結果透明度 0／40／100%、輸入邊界及切頁後狀態均通過。

## 4. 刪除與啟動行為

1. 提供刪除明確選取圖片與刪除專案全部圖片兩個入口；確認視窗列出張數、跨標註集影響與不可 Undo，無需輸入文字。
2. 刪除使用不可變圖片 ID，完成後更新連續顯示序號、清單、目前圖片及畫布；刪除全部不受篩選影響。
3. 啟動時將主視窗預設為最大化，確認一般視窗仍可由使用者調整。

**驗證：** Ctrl／Shift 多選、搜尋／篩選後刪除選取、篩選後刪除全部、取消確認、缺失圖片、最後一張及全部刪光、失敗回滾、重開專案、最大化與高 DPI 版面均通過。

## 5. 整合驗收與文件一致性

1. 執行 Release x64、相關自動測試及 JSON／ZIP 往返；使用合成素材檢查匯入至標註、刪除及重新連結完整流程。
2. 在 Windows 以 1366×768、1920×1080 與 100%～200% DPI 檢查按鈕、進度、清單欄位、下拉選單、畫布與控制點可見且可操作。
3. 核對本增量規格、領域詞彙、ADR 與舊規格；記錄實際結果及任何未達門檻的案例。
4. 在 `annotation-workflow-import-update` 分支呈現差異、測試與驗收證據；等待使用者明確確認全部修改完成，之後才合併 `main`。

**驗證：** 13 項需求各有可觀察的驗收證據；任何資料遺失、SEG 舊填色消失、JSON 錯映射、無效顏色部分寫入或刪除範圍錯誤均阻止完成。GitHub 上的工作分支與 `main` 保持分離，直到使用者確認。

## 主要失敗情境

- BMP 先轉檔後寫資料庫，途中取消或 I/O 失敗留下孤兒檔；必須在單張安全邊界清理或回滾。
- 轉檔後顯示名稱、受管理檔名、來源雜湊與原檔重新連結混用，導致 JSON 錯映射或無法修復缺圖；應以不可變圖片 ID 維持關聯並分別驗證名稱與來源內容。
- 顏色資料正規化後，畫布與色彩選擇器仍使用舊解析方式；須以真實 `rgba(...)-custom` 值做顯示與往返測試。
- SEG 路徑方向或洞橋接使 Non-Zero 填色相減；以像素遮罩比對加入前後的集合包含關係。
- 清單更新時逐圖片查庫，或排序／切換標註集造成選取與畫布不同步；以 10,000 張及快速切換驗收。
- 多選控制點彼此覆蓋或高 DPI 下截斷；以實際命中、可見層級及不同縮放倍率驗收。
- 刪除全部錯用篩選後可見 ID，或刪除選取錯用整個清單；兩個入口分別對照確認張數與刪除後 ID 集合。
