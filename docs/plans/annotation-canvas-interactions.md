# 畫布互動、標註複製與集體旋轉實施計畫

## 範圍與完成條件

- 以[增量正式規格](../specs/annotation-canvas-interactions.md)為驗收契約。本階段先建立文件；程式修改待文件確認後依序執行。
- 工作維持在 `annotation-canvas-interactions` 分支。完成程式、測試與差異審查後上傳 GitHub，建立指向 `main` 的 Draft PR；自動測試與 CI 不取代使用者的 Windows 桌面驗收，合併須另有明確指示。
- 成功標準是 13 項需求及逐題確認的補充規則均有可觀察的驗收證據，OBD／SEG 資料在儲存、重開、Undo/Redo 與 JSON 往返後仍正確，且既有資料不被改寫。

## 1. 基線、規格與回歸案例

1. 核對工作樹、現有 Release x64 建置與非互動測試結果；記錄既有失敗，避免把舊問題算成本次變更。
2. 以小型 SEG 路徑重現筆刷折返接近起點時的封閉多邊形結果；保存預覽、完成後填色遮罩與匯出結果。以矩形、橢圓、筆畫及有洞區域建立選取／旋轉樣本。
3. 核對目前 `F`、共用寬度、類別按鈕、圖片多選、視角及 Undo/Redo 接線；先證明實際缺口，再做最小修改。舊文件的「多選旋轉範圍外」以本次正式規格取代。

**驗證：** 回歸案例能顯示筆刷意外封閉、OBD 新標註固定使用第一類、單物件旋轉預覽、批次貼上缺口；既有功能基線清楚可重現。

## 2. 畫布回饋、筆刷與選取

1. 在畫布繪製層統一工具指標與預覽：選取箭頭，矩形／圓形／畫筆十字，有寬度工具的圓環與 `+`／`−`；作用中工具按鈕標示背景與外框。
2. 筆刷路徑始終以圓筆頭、圓角連接的有寬度塗抹完成；移除筆刷接近起點時轉成閉合填色的分支。補上筆刷與橡皮擦單擊圓形操作，靠邊時將筆頭中心限制在圖片內。畫筆預覽改為約 3px 線與全程可見的約 8px 實心起點；矩形及圓形加上固定 40% 類別色填色與清楚外框。
3. 以空白畫布左鍵拖曳開始框選。OBD 判斷矩形重疊，SEG 判斷實際填色或筆畫與框選區域重疊，包含洞的排除。普通框選取代選取；Ctrl+框選取聯集；從標註或控制點開始仍依既有移動、縮放、旋轉處理。
4. OBD 新建物件改用目前選取類別；OBD／SEG 類別按鈕以不遮蔽類別底色的外框標示落筆類別。同標註集切圖維持選擇，每次切換標註集回到其第一個類別。CLA 標出目前圖片已指派的類別。

**驗證：** 路徑折返、單擊、邊界、不同倍率、透明度 0／40／100%、不規則 SEG 與洞、Ctrl 框選及同集切圖均得到正式規格中的畫面與資料結果；既有畫筆閉環、Ctrl+點選及單物件編輯未退化。

## 3. 視角、顯示與快捷鍵

1. 將水平與垂直捲軸映射到同一畫布視角，只有對應方向超出可視範圍時顯示；右鍵拖曳與滾輪、縮放、適合視窗共用兩軸邊界。避免捲軸出現後縮小可視區引發反覆顯示／隱藏。
2. 讓 `F` 在標註工具模式仍可到達適合視窗命令；未完成繪製或拖曳時先取消當次預覽，文字輸入不受影響。`Z`／`X` 在 SEG 頁以 1 為步長調整 1–100 共用寬度，當次有寬度操作鎖定開始值，與 `Ctrl+Z` 等既有組合鍵分開。
3. 在標註頁加入與 `[` 同步的「顯示標註」勾選。隱藏期間停用既有物件命中及編輯，但保留新標註預覽和提交；結果提交後仍隱藏。切圖與切標註集保留狀態，重開專案恢復顯示。
4. 選單新增「說明 → 快捷鍵」列表，完整列出新舊按鍵、滑鼠操作和適用情境，與實際接線核對。

**驗證：** `F`、捲軸及右鍵平移在不同頁籤、倍率和視窗尺寸下不越界；隱藏不改資料或匯出；文字欄位與原有 Undo/Redo、上下鍵、Esc、Delete 均維持原用途。

## 4. OBD／SEG 複製貼上

1. 在主視窗保存本次執行期間的已選物件快照及其標註集身分；無已選物件的 `Ctrl+C` 不覆蓋原快照。切換圖片不改快照；跨標註集不貼上。類別已刪除時整次停止並顯示短暫 Toast。
2. 新增一個批次貼上儲存用例。對明確選取的每張目標圖片逐物件檢查原像素座標與幾何外接矩形；只略過超界物件，不輸出略過提示。合法物件取得新 ID，保留類別與同批相對層級，並排在目標圖片既有物件上方；SEG 複本保持獨立，不走新繪製聯集。
3. 將一次 `Ctrl+V` 成功產生的全部物件納入單一交易與單一完成操作歷史。意外持久化失敗時回滾整次寫入；沒有任何合法物件時不新增歷史。成功貼到目前圖片後改選其新複本，不自動切圖。

**驗證：** OBD／SEG 同圖與跨圖、多圖包含來源圖、每圖部分物件超界、複本完全重疊、快照後來源變動、類別刪除、資料庫錯誤、一次 Undo/Redo、重開與 JSON 往返均正確；沒有越界幾何或部分失敗的殘留紀錄。

## 5. 多選 SEG 旋轉

1. 拖曳任一已選 SEG 區域的旋轉點時，以同一滑鼠角度差計算所有已選區域的新幾何，各自使用自身中心；不更改多選縮放的單物件語意。
2. 旋轉預覽保留各物件尚未提交的角度，讓外接矩形與控制點同步旋轉；只有所有區域均在圖片範圍內才更新整組預覽。滑鼠放開後提交為一個完成操作，並按結果幾何重算軸對齊外接矩形與控制點。

**驗證：** 矩形、橢圓、筆畫、有洞路徑混選時角度一致、中心不位移、旋轉預覽可見；任一物件超界時整組停在最後合法角度；單物件縮放、Undo/Redo、儲存重開及 JSON 的固定旋轉角語意維持正確。

## 6. 整合驗收與 GitHub 交付

1. 執行 Release x64 建置、相關 MSTest、SEG 遮罩與持久化整合測試、JSON 往返及便攜發佈檢查。只在有具體風險時擴大測試，不重複只鏡像實作的低價值測試。
2. 在 Windows 實際操作 1366×768、1920×1080、100%～200% DPI 的工具指標、類別外框、滑鼠框選、畫筆起點、捲軸、右鍵平移、多選旋轉及隱藏繪製；另外量測連續 SEG 操作與多圖貼上的介面回應。
3. 審查只包含本次需求的差異、文件與測試結果，確認無不相關資料或檔案被納入。上傳 `annotation-canvas-interactions` 分支，建立 Draft PR，附上已通過與待使用者桌面驗收的證據。保留與 `main` 分離，直到使用者另行明確要求合併。

**驗證：** 自動測試、CI 與實際桌面驗收各有獨立結論；Draft PR 的差異、分支與遠端狀態可核對，沒有未解決的資料錯誤或意外合併。

## 主要失敗情境

- 筆刷預覽改成圓角，但提交路徑仍被封成多邊形；以提交後填色遮罩、重開及 JSON 驗證，不只檢查畫面線條。
- 筆刷或橡皮擦靠邊時圓環仍跟著原滑鼠點、實際筆頭中心卻被限制，造成提示與結果不一致；顯示落點應對應實際中心。
- SEG 洞或稀疏筆畫只因外接矩形碰到框選框就被誤選；以實際區域交集驗證。
- 捲軸顯示改變畫布尺寸，造成適合視窗與捲軸反覆切換、平移露出空白；以兩軸獨立邊界及切圖／切頁驗證。
- 多圖貼上逐物件建立歷史，讓一次 Undo 只撤銷部分圖片；以單次歷史與失敗回滾的資料庫整合測試驗證。
- SEG 複本誤用新繪製聯集，貼回原圖後複本消失；以新 ID、物件數及選取／移動驗證。
- 多選旋轉只旋轉主物件或控制點仍停在軸對齊框上；以每個物件在拖曳期間的可見外框、控制點及完成幾何驗證。
