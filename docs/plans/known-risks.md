# Neurocle 已知風險與控制措施

| ID | 風險 | 影響 | 已決定的控制措施 | 接受／停止條件 |
|---|---|---|---|---|
| R-01 | SEG 自交、洞、重複點、差集與旋轉的語意複雜 | 標註顯示或匯出錯誤、資料不可逆變形 | Clipper2、Non-Zero、整數核心、正式開發前原型與參考 JSON 回歸 | 原型未全數通過即停止正式 SEG 開發並新增 ADR |
| R-02 | 完成操作四捨五入可能使邊界附近形狀越界或退化 | 無效幾何、像素偏差 | 預覽與提交分離；提交時四捨五入、再做合法性及邊界檢查 | 退化操作拒絕提交；不得靜默保存越界幾何 |
| R-03 | 自動切分把漏標圖片當成有效負樣本 | 後續模型品質下降 | 資料集頁顯示空標註數量與警告；保留 clear set／not_used | 產品行為已接受；第一版不執行訓練 |
| R-04 | 相同內容圖片被獨立分到 train/test | 資料洩漏造成評估偏高 | 保存 SHA-256，切分結果可顯示重複內容警告，但不強制綁定 | 已接受非可重現、獨立分配行為 |
| R-05 | 隨機切分不保存種子 | 無法重現先前切分 | 每次結果立即保存；Undo 可還原最近操作 | 已接受；第一版不新增種子設定 |
| R-06 | 同名標註集且選單不顯示 ID | 使用者選錯資料集或刪錯 | 刪除需輸入完整名稱；型別與名稱並列；內部資料以 ID 隔離 | 誤選風險已接受，不自行禁止重名 |
| R-07 | 圖片檔與 SQLite 分離 | 搬移不完整或外部刪檔造成缺失 | 受管理目錄、開啟時檢查、SHA-256 重新連結、備份介面明示不含圖片 | 缺圖不匯出；永久移除時刪除其標註 |
| R-08 | 備份只含資料庫且僅保留五份 | 圖片損失或較舊狀態無法復原 | 明確顯示範圍；還原前備份目前 DB；鼓勵使用者外部複製完整專案 | 這是已確認的產品限制 |
| R-09 | 日誌永久保留 | `%LocalAppData%` 磁碟耗盡 | 顯示用量、提供開啟資料夾；不記錄大體積座標或影像 | 不自動刪除是明確需求，磁碟不足時清楚失敗 |
| R-10 | 大圖與 10,000 張專案壓迫 HDD、RAM 與 UI 執行緒 | 卡頓、OutOfMemory、未回應 | 虛擬清單、限制解碼快取、背景 I/O、取消、指定效能閘門 | 不達效能門檻不得通過相應階段 |
| R-11 | Undo 每標註集可達 512 MiB | 多標註集造成高記憶體用量 | 100 動作／512 MiB 雙限制、最舊淘汰、壓力測試與 UI 顯示不可復原界線 | 發生記憶體壓力時不得突破資料一致性 |
| R-12 | 部分成功圖片匯入與同時編輯可能競爭 | 序號、集合初始化或儲存不一致 | 每檔交易、序號單一分配器；匯入期間停用全域／批次命令 | 崩潰／取消測試必須保持已完成項目一致 |
| R-13 | JSON 匯入參考格式未正式版本化 | 未知欄位或新 region 造成錯誤解讀 | 嚴格驗證、原子寫入、未知欄位警告後丟棄、固定支援版本行為 | 不猜測未知語意；致命不相容整批拒絕 |
| R-14 | 未修改路徑需逐點保存，編輯後又需幾何正規化 | Round-trip 難以同時滿足位元級與語意級要求 | 保存原始交換表示與 dirty 狀態；只有幾何編輯後改用正規化輸出 | 未修改逐點一致；修改後以遮罩語意一致驗收 |
| R-15 | 本機檔案鎖、突然斷電或資料庫損毀 | 工作遺失或專案無法開啟 | SQLite 交易、完成操作自動存檔、每日／遷移前備份、損毀提示 | 不可靜默開啟可疑 DB 並覆寫 |
| R-16 | 可攜式 ZIP 漏帶原生 SQLite 或授權檔 | 離線電腦無法啟動或授權不完整 | CI 檔案清單檢查、全新斷網電腦驗收、第三方聲明 | 任一缺失即阻止發佈 |
| R-17 | Windows hosted CI 無法可靠操作 WinForms | UI 缺陷未被 CI 發現 | 規則下沉到可自動測試層；UI Automation 與 DPI 在指定電腦逐階段執行 | 不以 CI 綠燈取代本機 UI 驗收 |
| R-18 | 儲存庫目前公開且歷史含完整資料集 | 即使之後刪除，既有公開複本仍可能存在 | 另案先備份、改私人、歷史重寫、只保留小型合成資料；揭露無法撤回既有曝光 | 未另行授權前不執行破壞性 Git 操作 |
| R-19 | 使用者刪除圖片或標註集不可 Undo | 大量資料永久遺失 | 明確確認；標註集要求輸入完整名稱；圖片列出影響範圍 | 需求明確指定無 Undo，測試不得暗示可復原 |
| R-20 | 不支援網路／同步／可移除磁碟可能被路徑偵測繞過 | 檔案鎖或中途離線造成損毀 | 建立／開啟時檢查磁碟類型與已知同步位置，拒絕並解釋 | 無法可靠判定的路徑採保守拒絕並記錄原因 |
| R-21 | SEG 完成事件同步執行幾何與儲存，且重疊區域多時可能反覆讀取及聯集 | 筆畫放開後卡頓、切圖競爭、重複或錯誤提交 | 先分段量測；針對瓶頸修正；運算中保持 UI 回應，專案寫入序列化，切圖在安全提交後執行 | 現有素材及約 17,000 點案例逐筆不超過 1 秒，且無錯圖、遺失或重複提交 |
| R-22 | 最近邊緣橋接遇到凹形外圈、多洞、等距端點或整數化後交叉 | 洞填色或 JSON 語意錯誤 | 只處理新生成／編輯後區域；檢查連線合法性、Non-Zero 面積與往返；未修改匯入路徑保留 | 任一合法性或語意回歸失敗不得交付 SEG 修訂 |
| R-23 | 左清單、中畫布、右工具在高 DPI 下空間競爭 | 控制項截斷、畫布過小或兩頁尺寸不同 | 正常視窗至少增加約 25% 高度；小尺寸縮窄欄位、內容捲動並保留兩側可見 | 1366×768、100%～200% DPI 均可操作且重要控制項不截斷 |
| R-24 | 三種匯入若各自啟動背景工作會同時寫入同一專案 | 圖片序號、集合初始化、JSON 與工作狀態競爭或部分損毀 | 依 ADR-0005 使用專案範圍單一 FIFO；下一項只在前項安全結束後開始；專案切換受鎖定 | 任一時序測試出現重疊寫入、已處置專案存取或半份 JSON 即停止交付 |
| R-25 | 匯入工作等待期間來源被移動、刪除或修改 | 執行結果與排隊時預期不同 | 只保存路徑與選項，執行時驗證；結果卡片記錄成功、略過、失敗或取消，不建立隱藏快照 | 不得匯入錯誤來源或把來源漂移誤報為成功；單項失敗不得阻止安全的後續工作 |
| R-26 | 標註隱藏時仍允許 Ctrl 擦除與橡皮擦 | 使用者看不到既有填色時可能誤刪 SEG | 保留 40% 幾何預覽、游標右下角 `−`、目前類別隔離及單次 Undo/Redo；桌面驗收特別覆蓋 | 預覽與結果範圍不一致、影響其他類別或無法一次復原即停止交付 |
| R-27 | 動態匯入卡片、資料集右欄及類別列在高 DPI 累積高度或寬度 | 操作截斷、畫布／清單過小、狀態不可讀 | 卡片與右欄可垂直捲動、長文字省略與 ToolTip、DPI 縮放；1366×768 與 100%／150%／200% 實機驗收 | 任一主要操作不可達、清單寬度為零或狀態文字不可辨識即不得合併 |
| R-28 | 切分所選只在 UI 過濾候選，但儲存層仍覆寫全部圖片 | 未選圖片的資料集狀態被意外改寫 | 規劃與持久化都接受明確圖片 ID 範圍；逐筆比對範圍外狀態與 Retest，整次單一交易／Undo | 任一範圍外資料變更或部分寫入即停止交付 |
| R-29 | Designer 接線與原程式接線重複，全面 XML 文件差異又遮蔽行為改動 | 事件執行兩次、難以審查或維護 | 只搬屬性頁可見固定事件、逐項搜尋原接線、具名處理函式；文件整理獨立提交 | 任一單次事件重複觸發、Designer 無法開啟或文件提交混入行為變更即不得合併 |
| R-30 | 匯入與匯出若仍由不同背景流程執行 | 輸出讀到半份匯入、SQLite 競爭或已處置專案 | 依 ADR-0006 使用單一專案工作 FIFO；跨類型時序測試證明一次只執行一項 | 任一重疊專案 I/O、錯序或不一致快照即停止交付 |
| R-31 | JSON 取代目前標註集且明確不可 Undo/Redo | 誤選模式造成大量既有標註永久被取代 | 設定前完整預覽、作用範圍模式、不可復原二次確認與單一交易回滾 | 未確認即執行、範圍外資料變更或任何部分寫入即停止交付 |
| R-32 | 排隊匯出直接寫最終檔或取消未清理 | 留下半份 JSON／ZIP、覆寫既有檔或累積暫存 | 同目錄暫存、成功後唯一名稱發布、取消／失敗／關閉清理、結果卡片記錄實際路徑 | 任一半成品被當成成功、既有檔遭覆寫或暫存殘留未揭露即停止交付 |
| R-33 | Ctrl 擦除平均 FPS 達標但仍有偶發長停頓 | 使用者仍感到游標與預覽卡頓 | 真實畫布與 17,000 點素材量測平均、p95、最大單幀；一般／Ctrl 使用同路徑 | 平均低於 60 FPS、p95 超過 33.3ms 或任一單幀超過 100ms 即不得合併 |
| R-34 | 縮圖在未完成手勢中搶事件或取消後未恢復 | 標註被截斷、視野誤移動或縮圖永久消失 | 手勢期間隱藏縮圖；完成、Esc、切圖、切集、切工具與切頁共用恢復出口 | 任一路徑讓縮圖提前出現、未恢復或同一手勢進入兩種模式即停止交付 |
| R-35 | JSON 預檢後來源檔在等待期間變更 | 預覽與實際匯入內容不同、錯型資料寫入目前標註集 | 只保存路徑與選項，執行時重新完整驗證；型別或未知欄位漂移形成失敗工作 | 不得依過期預覽寫入，任何錯型或未同意欄位進入專案即停止交付 |

## 風險檢視時點

- 每一階段開始前重新檢查與該階段有關的風險。
- 任一「停止條件」發生時不得以縮小測試或手動修改資料繞過，必須記錄新 ADR 或修訂規格。
- 只有使用者可接受新的產品風險；實作者不得將技術限制默默轉成產品行為。
